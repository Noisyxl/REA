## 🧙 What is REA?

**REA (Reverse Engineer Anything)** is an open-source toolkit that lets AI agents like **Claude (Opus 5.5)**, **Codex**, or **Cursor** analyze any software and explain how it works. It can read desktop apps, websites, games, Android APKs, smart contracts and more, providing clear explanations with real evidence from the code.

## ⚡ Why use it?

- 🔍 Understand how features work inside any application
- 📂 Get exact files, functions and logic with evidence
- 🛠️ Learn, audit, and build your own versions
- 🎓 Useful for research, education, security and interoperability
